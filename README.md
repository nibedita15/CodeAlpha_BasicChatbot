# 🤖 Basic Chatbot

A simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Description

This chatbot interacts with users through text-based conversations. It responds to common greetings, basic questions, jokes, date/time requests, and farewell messages using predefined rules.

## ✨ Features

- Greets users
- Responds to common questions
- Tells programming jokes
- Shows current date and time
- Handles thank-you messages
- Exits gracefully when the user types "bye"

## 🛠️ Technologies Used

- Python 3
- Functions
- Conditional Statements
- Loops
- Datetime Module

## 🚀 How to Run

1. Download the project files.
2. Open a terminal in the project folder.
3. Run:

```bash
python chatbot.py
```
